Contains unit tests for the AppReal command. These tests focus on parameter validation and compile-time validation, and account for BOOSE runtime typing rules which require a true "real" variable to successfully call UpdateVariable(string, double).

Remarks

In this BOOSE build, registering a variable name via BOOSE.StoredProgram.AddVariable(BOOSE.Evaluation) does not make it a typed "real" variable. As a result, Execute() will throw a BOOSE.CommandException ("Type mismatch, expected a real value") when it attempts to update the variable. The execution tests below assert that expected behavior.
