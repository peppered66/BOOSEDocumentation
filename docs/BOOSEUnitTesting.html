AppArrayTests

Contains unit tests for the AppArray class. These tests validate correct parameter parsing, compilation, execution, and array access behavior for both integer and real arrays.

AppCanvasTests

Contains comprehensive unit tests for AppCanvas.

AppCommandFactoryTests

Contains unit tests for the AppCommandFactory class. Verifies that the factory returns the correct command type for each supported command name (case-insensitive and whitespace tolerant) and throws BOOSE.FactoryException for unknown commands.

AppElseTests
AppEndForTests

Unit tests for AppEndFor. These tests validate parameter rules, runtime stack behaviour, and loop-finish vs loop-continue decisions without asserting on StoredProgram's runner-controlled PC behaviour.

AppEndIfTests

Unit tests for AppEndIf. Validates parameter rules and runtime stack behaviour when ending an if-block.

AppEndWhileTests

Unit tests for AppEndWhile. These tests validate runtime-stack behaviour and error handling. PC-jump behaviour is intentionally not asserted here because it is runner/integration behaviour and can vary depending on StoredProgram implementation.

AppForTests

Unit tests for AppFor. Validates syntax checking, auto-variable creation, compile-time type validation, execution behaviour across iterations, and step handling.

AppIfTests

Unit tests for AppIf. Focuses on condition evaluation and branch decision logic without relying on StoredProgram's execution loop.

AppIntTests

Contains unit tests for the AppInt command. Tests cover parameter validation, compile-time validation (variable existence), and execution-time evaluation/updating of an integer variable.

AppPeekTests

Contains unit tests for the AppPeek command. Tests cover parameter validation/parsing, compile-time validation (variable/array existence), and execution-time behavior for reading values from AppArray instances.

AppPokeTests

Contains unit tests for the AppPoke command. Tests cover parameter validation/parsing, compile-time validation (array existence), and execution-time behavior for writing values into AppArray elements.

AppRealTests

Contains unit tests for the AppReal command. These tests focus on parameter validation and compile-time validation, and account for BOOSE runtime typing rules which require a true "real" variable to successfully call UpdateVariable(string, double).

AppWhileTests

Unit tests for AppWhile. Validates condition evaluation, operator validation, and loop exit behaviour without relying on program runner.

CircleCommandTests

Contains unit tests for the CircleCommand class. Tests cover parameter validation, compile-time validation for literal inputs, and execution-time behavior for literal radius values.

CommandParserTests

Unit tests for CommandParser. Covers parsing of single-line commands (including special-cased "end if/while/for"), variable declarations (int/real), assignments, and loop/if structure validation.

DrawToCommandTests

Contains unit tests for the DrawToCommand class. Tests cover parameter validation, compile-time validation for literal inputs, and execution-time behavior for literal and evaluated parameters.

MoveToCommandTests

Contains unit tests for the MoveToCommand class. Tests cover parameter validation, compile-time validation for literal inputs, and execution-time behavior for literal and evaluated parameters.

PenCommandTests

Contains unit tests for the PenCommand class. Tests cover parameter validation, compile-time validation for literal RGB values, and execution-time behavior including runtime range checking.

RectangleCommandTests

Contains unit tests for the RectangleCommand class. Tests cover parameter validation, compile-time validation for literal inputs, and execution-time behavior for literal and evaluated parameters.

TestBase

Provides common setup for BOOSE command unit tests, including a BOOSE.StoredProgram created with a headless BOOSE.ICanvas.

WriteCommandTests

Contains unit tests for the WriteCommand class. Tests cover parameter validation and execution behavior for both evaluated text and literal (fallback) text.
