Remarks

BOOSE enforces strict runtime typing for UpdateVariable(string, int) and UpdateVariable(string, double). In this project, registering a variable name via BOOSE.StoredProgram.AddVariable(BOOSE.Evaluation) does not make it a typed BOOSE int/real variable, so execution tests that attempt to update a scalar variable will typically throw BOOSE.CommandException (type mismatch).

The execution tests below therefore focus on:

  • validation paths (missing array/variable, not-an-array, out-of-bounds)
  • successful retrieval from the array (verified by the array still holding the expected value)
  • and the fact that a scalar update attempt occurs (observed via the expected BOOSE type-mismatch exception).
